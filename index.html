Page Notification

A page notification is a type of notification that appears at the bottom left of a page. They are used to give users feedback after they've performed an action and notify them of errors or issues. They can be dismissed by users. They are also referred to as toast message and page toast.

Also called: toast message · page toast Storybook ↗ Figma ↗ Updated Sep 2026

Variants

A page notification can have four statuses, depending on the nature of the message.

  • Info — inform the user that an action has been initiated, or give them a system update.
  • Success — inform the user that an action has been completed successfully.
  • Warning — inform the user of an issue that isn't a blocking error, and guide them to an optional or mandatory next step.
  • Critical — inform the user why the action couldn't be completed, and guide them to the next step.

A page notification can be single-line or multi-line, depending on how much detail is required.

Best practices

✓Do

Use the page notification only at the page level.

✕Don't

Don't use the page notification in combination with another surface like the modal.

✓Do

Use links in the page notification to direct users to a next step.

✕Don't

Don't use action components like buttons in page notifications.

Figma how-to guide

Single-line notification. If the notification is concise, use the single-line variant by selecting "single" from the dropdown menu for Line.

Multi-line notification. If the text gets truncated, the notification has reached the maximum width. Select "multi" from the dropdown menu for Line.

Behavior

Automatic time out

Users can dismiss page notifications manually using the X in the upper right-hand corner. Page notifications will time out and dismiss automatically after 8 seconds.

Exception

The error (critical) message won't automatically go away until the user manually dismisses it.

The page notification should persist in its hover state and goes away 8 seconds after users mouse away. Pulse and reset the dismiss timer when the user's focal point is not on the current browser.

Multiple notifications

When there is more than 1 notification, stack notifications with margin-bottom: 16px. Newer notification will be at the bottom, following the same fade in/out rule. Max number of notifications on stacking is 3: additional notifications will be queued and appear after earlier notifications disappear.
